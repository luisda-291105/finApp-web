# Feature: En desarrollo

## Qué hace

Provee un aviso informativo reutilizable para indicar que una sección está en creación o mantenimiento, sin interrumpir su funcionamiento.

## Componentes

- `components/AvisoEnDesarrollo`: mensaje informativo configurable (título y texto).

## API pública

`index.js` expone `AvisoEnDesarrollo` para que otros features lo integren en sus páginas.
