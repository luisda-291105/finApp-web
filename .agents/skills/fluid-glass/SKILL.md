# SKILL: fluid-glass

Glassmorphism estilo visionOS/iOS 18+.

## reglas
- backdrop-filter: blur(20-30px) saturate(160-200%) + fallback sólido
- border-radius 20-28px, sin bordes cuadrados/sombras duras
- borde superior highlight en todo elemento de vidrio
- máx 3 capas de vidrio por vista, máx 2 blobs CSS por viewport
- contraste mínimo AA

## uso
Aplicar a: cards, navbar, modal, paneles CTA.
